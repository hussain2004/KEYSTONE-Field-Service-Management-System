# Keystone Field Service Management System

## Overview

Keystone Field Service Management System is a full-stack web application developed to manage field service operations efficiently. It provides secure authentication, role-based access control, customer management, technician management, work order tracking, inventory management, and reporting.

---

## Features

- JWT Authentication
- Role-Based Authorization (Admin & Engineer)
- Dashboard
- Customer Management
- Site Management
- Technician Management
- Work Order Management
- Parts Management
- Dispatch Management
- Reports
- Responsive User Interface
